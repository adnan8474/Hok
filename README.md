# POCTIFY Interactive Tools Landing Page

This repository contains a simple React-based landing page for showcasing POCTIFY tools. It is designed to be deployed on Netlify without any build step.

## Running locally

Open `index.html` in a browser. All dependencies are loaded via CDN.

## Deployment

Deploy the root directory to Netlify. Ensure your logo image is named `poctify-logo.png` and placed in the same directory as `index.html`.
